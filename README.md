# Цели и Настроение

Личный сайт: цели/мечты на год + приватный трекер настроения + ИИ-анализ (Google Gemini).
Все данные хранятся в твоей Google Таблице через Google Apps Script.
Работает с ПК и с телефона (в одной Wi-Fi сети) с фоновой синхронизацией. Вход защищён паролем.

Без npm-зависимостей — только встроенный Node.js.

## Быстрый запуск (после клонирования с GitHub)

1. Установи [Node.js](https://nodejs.org) (LTS), если ещё не установлен.
2. Скопируй `config.example.json` в `config.json` и заполни:
   - `sheetWebAppUrl` — ссылка на твой Google Apps Script web app (см. раздел "Google Таблица и Apps Script" ниже).
   - `geminiApiKey` — опционально, бесплатный ключ с https://aistudio.google.com/apikey (без него сайт работает, просто вкладка "ИИ" не отвечает).
3. Дважды кликни **start.bat** (Windows) — откроется консоль с сервером и браузер на `http://localhost:3838`.
   На Mac/Linux: `node server.js`.
4. При первом входе задай себе пароль (кнопка настроек справа вверху → «Сохранить пароль»), либо через API `/api/auth/set-password`. Пока пароль не задан, вход в сайт открыт без пароля.

В консоли также будет ссылка вида `http://192.168.x.x:3838` — открой её в браузере телефона (та же Wi-Fi сеть).

## Google Таблица и Apps Script

Нужна отдельная Google Таблица со скриптом Apps Script (`Код.gs`), который отдаёт/принимает данные через `doGet`/`doPost`.
Если у тебя его ещё нет:
1. Создай новую Google Таблицу.
2. Расширения → Apps Script.
3. Вставь код бэкенда (листы `Goals`, `Mood`, `Settings` создаются скриптом автоматически при первом обращении).
4. Deploy → New deployment → Web app → Execute as: **me**, Who has access: **Anyone** (или "Anyone with the link").
5. Скопируй выданный URL `.../exec` в `config.json` → `sheetWebAppUrl`.

⚠️ Этот URL даёт доступ на чтение/запись твоей таблицы (цели, настроение, хэш пароля) — никому его не показывай и не публикуй.
Поэтому `config.json` специально в `.gitignore` и не должен попадать в репозиторий.

## Структура файлов

- `public/` — сам сайт (HTML/CSS/JS).
- `server.js` — локальный сервер (Node.js, без зависимостей). Прячет ключ ИИ от браузера, проксирует запросы к Apps Script, авторизация по паролю (сессии на 30 дней), отдаёт LAN-адрес при запуске.
- `prompts.js` — промпты для ИИ-анализа.
- `config.example.json` — шаблон конфига. Скопируй в `config.json` и заполни своими значениями.
- `start.bat` — запуск на Windows одним двойным кликом.

## Логика целей

Добавление цели — через модальное окно: название, описание, категория, год, тэги.
Статус/прогресс/комментарий редактируются отдельно — клик по карточке цели открывает модалку "Прогресс по цели".

Статусы: **Цель** (не начато) → **В процессе** → **Частично выполнено** / **Полностью выполнено** / **Не выполнено**
(с кнопкой "Перенести на следующий год").

## ИИ-анализ

Вкладка «ИИ»: выбираешь тип анализа (цели/настроение) и период — кнопками или кликом по одному/нескольким столбикам графика.
Промпт для ИИ автоматически учитывает выбранный период.

## Пароль и настройки

Кнопка-шестерёнка справа вверху открывает модалку: переключение темы (тёмная/светлая) и смена пароля.
Пароль хранится как SHA-256 хэш (с локальной солью) в листе `Settings` твоей таблицы — сам пароль на сервер/в таблицу никогда не отправляется в открытом виде.
Сессия входа живёт 30 дней (не спросит пароль каждый раз), пока не нажмёшь «Выйти».

## Если понадобится изменить Apps Script

Открой таблицу → Расширения → Apps Script → правки в `Код.gs` → Deploy → Manage deployments → Edit (карандаш) → New version → Deploy.
Это обновит тот же самый URL, ничего не сломается.
